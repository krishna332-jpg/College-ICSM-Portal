# College ICSM Portal

A full-stack web application designed to manage internships, scholarships, and certification opportunities within a college environment.

## Features

- Role-based authentication (Admin & Student)
- Opportunity management system (Internships, Scholarships, Certifications)
- Application tracking system
- Dynamic form builder for customizable application forms
- Admin dashboard with data management
- Messaging system between students and admin
- File upload and secure data handling

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
